# Aerospace-Manufacturing
An end-to-end Power BI Manufacturing Analytics Solution for a simulated aerospace manufacturing environment.
---
# Project Scope
Industry: Aerospace Manufacturing
Department: Production
Workforce: 600 Employees across 3 shifts
Period: January–June 2026
---
# Data Volume
51,000 Production Orders
204,000 Production Operations
130,000 Labor Transactions
2,000 Equipment Assets
200 Customers
40 Aerospace Products
---
# Data Model
Built a star-schema model consisting of:
- Employees
- Work Centers
- Customers
- Products
- Production Orders
- Production Operations
- Labor Tracking
- Equipment Master
- Calendar Table
---
# Power BI Solution
Designed a 10-page executive manufacturing dashboard covering:
- Executive Overview
- Production Order Management
- Operations Performance
- Labor Performance
- Workforce Management
- Equipment Reliability & Asset Management
- Quality & Rework Performance
- Customer & Product Performance
- Work Center Performance
- Operational Excellence
---
# Key Metrics
Overall Equipment Effectiveness (OEE)
First Pass Yield (FPY)
On-Time Delivery
Schedule Adherence
Labor Productivity
Equipment Productivity
Throughput
WIP
Rework Rate
Asset Utilization
MTBF / MTTR
Overtime Analysis
---
# Advanced Analytics
Implemented advanced DAX measures including:
- Rolling 30-Day Performance
- YTD Labor Hours
- Pareto Analysis (80/20)
- OEE Calculation
- Productivity Metrics
- Schedule Compliance
- Rework Tracking
- Workforce Utilization
- Asset Availability
- Operational Excellence Index

# Executive Insights
The dashboard enables leadership teams to:
- Monitor production flow in real time
- Identify bottlenecks across work centers
- Improve labor utilization
- Track equipment reliability
- Manage quality and rework performance
- Improve on-time delivery performance
- Drive continuous improvement initiatives
